# Introduction

The Logging module is a core component of the ACP platform's observability suite. It provides comprehensive log management capabilities for efficient and reliable log processing across every cluster on the platform.

This module delivers three essential capabilities:

- **Log collection** for automated gathering of standard-output logs, file logs, Kubernetes events, and audit records from applications, containers, and infrastructure components.
- **Log storage** for scalable and durable persistence into ClickHouse or OpenSearch (recommended) or Elasticsearch (retained for legacy customers).
- **Log querying** for fast, flexible search across large volumes of log data from the ACP console.

The Logging module delivers these capabilities through three cluster components — two plugins (**Alauda Container Platform Log Essentials** and **Alauda Container Platform Log Collector**) and one operator (**Alauda Container Platform Log Storage Management**) — layered on top of open-source components: `nevermore` (collection), Vector (data path), Kafka (buffering), and ClickHouse or OpenSearch (storage). One Log Storage Management operator covers both ClickHouse and OpenSearch backends; the backend choice is made in the `PlatformLogForward` CR, not in the operator install form. Together they enable organizations to handle massive log volumes, accelerate troubleshooting, meet compliance requirements, and gain operational insights in real time.
